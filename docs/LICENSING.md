# Licensing

The CLI scaffold is licensed under MIT. Vendored packages remain under their
respective upstream licenses; the repository license does not relicense them.

Before redistributing a vendor snapshot:

1. Inspect the SPDX expression and actual license files for every package.
2. Review dual-license choices and any special attribution/notice requirements.
3. Preserve copyright notices, license texts, and source attribution.
4. Review Git dependencies and forks separately; public availability does not
   itself grant redistribution rights.
5. Have a maintainer review unknown, custom, copyleft, or conflicting terms.

The sample allowlist is a starting point only and must be adapted to Cognix's
license obligations and distribution model.
